# 5通道圆形电容感应数据可视化系统

面向**平板压力夹爪**的 5 通道圆形电容式压力传感器上位机软件。
提供实时数据采集、信号处理、力学解算与多视图可视化能力。

## 功能特性

- **5 通道实时采集**：串口 115200 波特率，CSV 格式解析，三级线程 + 双队列流水线
- **多重滤波**：支持移动平均、指数平滑、卡尔曼滤波、中值滤波（可实时切换）
- **3D 受力场可视化**：基于加权质心算法定位受力中心，椭圆渐变表现压力分布，
  箭头指示剪切力方向，支持上下/左右镜像翻转
- **迷你热力图**：传感器电极分布热力图，色阶映射直观反映各通道强度
- **力学分析柱状图**：总压力 / 剪切合力向上显示，剪切 X / Y 双向正负显示，
  自动量程（上限 20000）
- **实时曲线图**：5 通道时间序列，X 轴时间窗口可调（1~120 秒），支持右键导出图像
- **自动归零**：无压力状态持续 0.1 秒后自动重设基准，抑制长期漂移
- **迟滞补偿**：检测释放趋势并分级加速衰减，解决柔性传感器释放后回零缓慢问题
- **噪声平抑**：±5 以内跳动信号自动归零，低于 30 的信号不影响图形显示（曲线图保留原始波形）
- **HTTP API**：连接后自动启动，对外提供原始数据与力学解算数据
- **SQLite 存储**：批量写入优化，支持 CSV 导出

## 界面与可视化

程序主界面分为三部分：

| 区域 | 内容 |
|------|------|
| 左侧控制面板 | 串口配置、数据处理（滤波算法/窗口）、统计信息、操作按钮 |
| 右上 | 3D 受力场分析（含左下角迷你热力图） + 力学分析柱状图 |
| 右下 | 5 通道实时曲线 + 通道数值标签 + API 状态 |

## 传感器布局

直径 **17mm** 圆形电容传感器，采用 **4 扇形 + 1 中心圆** 电极布局：

```
        ┌─────────────────┐
        │      CH2(上)     │
        │   ┌─────────┐   │
        │CH3│  CH4    │CH1│
        │(左)│ (中心)  │(右)│
        │   └─────────┘   │
        │      CH5(下)     │
        └─────────────────┘
```

| 通道 | 位置 | 电极类型 | 面积权重 | 归一化坐标 (x, y) |
|------|------|---------|---------|------------------|
| CH1 | 右 | 扇形 | 0.218 | (0.675, 0) |
| CH2 | 上 | 扇形 | 0.218 | (0, 0.675) |
| CH3 | 左 | 扇形 | 0.218 | (-0.675, 0) |
| CH4 | 中心 | 圆形 | 0.125 | (0, 0) |
| CH5 | 下 | 扇形 | 0.218 | (0, -0.675) |

硬件结构：4 层 PCB + 2 层 FPC + 0.1mm 膜材料。

## 快速开始

### 环境要求

- Windows 10 / 11（Linux / macOS 可运行源码，但单实例保护仅 Windows 生效）
- Python 3.8+

### 源码运行

```bash
# 1. 克隆仓库
git clone <your-repo-url>
cd <repo-dir>

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python src/main.py
```

### 打包为单文件 EXE

```bash
pip install pyinstaller
pyinstaller 5P_single.spec
# 产物：dist/5P_v1.6.exe
```

### 使用步骤

1. 用 USB 连接传感器硬件
2. 在「串口配置」中选择对应 COM 口与波特率（默认 115200）
3. 点击「连接串口」
4. 程序自动采集 0.1 秒数据作为初始基准并归零，随后开始实时显示
5. 需要重新标定零位时，在**空载状态**下点击「初始化归零」

## 算法说明

完整的算法原理、公式推导与参数调节指南请见
**[ALGORITHM_EXPLANATION.md](ALGORITHM_EXPLANATION.md)**。

核心处理流水线：

```
原始数据
  → 信号滤波（可选 4 种算法）
  → 初始归零（减去初始基准）
  → 微小噪声平抑（±5 以内归零）
  → 正值过滤（夹爪场景只关心按压力）
  → 迟滞补偿（释放检测 + 分级加速衰减）
  → 力学解算（总压力 + 剪切力）
  → 无压力自动归零检测
  → 有效信号过滤（<30 仅影响非曲线图视图）
  → 可视化 + API + 数据库
```

核心公式速览：

| 量 | 公式 |
|----|------|
| 加权总压力 | `P_raw = Σ(ΔCᵢ × wᵢ)` |
| 非线性补偿 | `P = 4.0 × P_raw − 0.0001 × P_raw²` |
| 质心 X | `cx = Σ(ΔCᵢ·wᵢ·xᵢ) / Σ(ΔCᵢ·wᵢ)` |
| 质心 Y | `cy = Σ(ΔCᵢ·wᵢ·yᵢ) / Σ(ΔCᵢ·wᵢ)` |
| 剪切力 | `Fsₓ = P × cx / r_sector`，`Fs_y = P × cy / r_sector` |
| 压缩补偿 | `Fs ×= 1 / (1 + 5e-5 × P)` |

## HTTP API 接口

串口连接成功后自动启动，默认监听 `0.0.0.0:5000`。

| 端点 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 端点列表与版本信息 |
| `/api/raw` | GET | 传感器原始数据（5 通道电容值） |
| `/api/force` | GET | 力学解算数据（总压力、剪切 X/Y、质心、等效半径） |
| `/api/all` | GET | 原始数据 + 力学数据 |
| `/api/status` | GET | API 服务器状态 |

示例：

```bash
curl http://127.0.0.1:5000/api/all
```

```json
{
  "timestamp": "2026-08-21T10:30:00.123456",
  "raw": {"ch1": 1578, "ch2": 1209, "ch3": 1242, "ch4": 1440, "ch5": 1237},

    "total_pressure": 5234.5,
    "shear_x": 123.4,
    "shear_y": -89.2,

    "center_x": 0.234,
    "center_y": -0.156,
```

## 数据存储与导出

- 所有采集数据自动写入 `data/sensor_data.db`（SQLite）
- 采用缓存 + 批量写入策略（缓存 1000 条或间隔 5 秒触发），避免高频 IO
- 界面「导出 CSV」按钮可将全部记录导出为 CSV
- 表结构：`sensor_data(id, timestamp, channel_0..4, created_at)`

> `data/` 目录与 `*.db` 文件已加入 `.gitignore`，不会被提交到仓库。

## 通信协议

上位机通过串口接收 ASCII CSV 格式数据，每帧以换行符 `\n` 结尾：

```
1578,1209,1242,1440,1237\n
```

- 5 个数值依次对应 CH1 ~ CH5 的电容读数
- 支持自动剥离日志前缀（如 `[19:18:43.638]收←◆`）
- 非法控制字符帧自动丢弃，UTF-8 解码容错

串口参数：**115200 8N1**，无硬件流控。
